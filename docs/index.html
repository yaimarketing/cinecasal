Verificando o servidor…

Ninguém transmite vídeo para ninguém. Cada pessoa abre o filme no próprio navegador, logada na própria conta. A extensão só manda os comandos de play, pause e tempo, e as mensagens do chat.

Como funciona

1Todos instalam a extensão no Chrome e entram na plataforma com a própria conta.
2Uma pessoa abre o vídeo, clica no ícone e cria a sala. Recebe um código de 6 letras.
3Os outros clicam no ícone, digitam o código e entram. A página avisa qual vídeo abrir.
4Quem criou a sala é o host: o play, pause e pular dele valem para todos. O chat fica na barra lateral.

Instalar a extensão (Chrome, Edge ou Brave)

  1. Baixe o .zip do projeto e descompacte. A extensão é a pasta extension.
  2. Abra chrome://extensions e ligue o Modo do desenvolvedor (canto superior direito).
  3. Clique em Carregar sem compactação e escolha a pasta extension.
  4. Fixe o ícone roxo na barra do navegador (ícone de quebra-cabeça → alfinete).

Todos precisam estar logados na plataforma e ter a extensão instalada. A extensão já vem apontando para o servidor público wss://cinecasal.onrender.com. Esse servidor dorme depois de 15 minutos sem uso: a primeira conexão do dia pode levar até um minuto.

Usar

  1. Abra o vídeo (YouTube, Netflix, Prime Video ou Max).
  2. Clique no ícone, digite seu nome e Criar sala. Copie o código e mande para quem vai assistir com você.
  3. Quem recebeu o código clica no ícone, digita o nome e o código e clica em Entrar. Se estiver em outro vídeo, aparece um aviso "O host está assistindo… clique para abrir".
  4. Pronto: o host controla, todo mundo acompanha. A barra lateral mostra quem está na sala, o chat e eventos como "Host pausou em 12:34". O botão › recolhe a barra.

Quer seu próprio servidor?

O servidor é pequeno e gratuito de hospedar. Com uma conta no Render, clique abaixo e aceite o blueprint do repositório. Depois, no popup da extensão, abra Avançado: servidor e coloque o endereço wss://SEU-APP.onrender.com.

Deploy no Render

Também dá para rodar no computador: cd server && npm install && npm start e usar ws://localhost:8080 na extensão. Instruções para Railway e Fly.io estão no README do servidor.

Limitações conhecidas

  • Netflix, Prime e Max mudam o player com frequência. O YouTube foi testado de ponta a ponta; os outros precisam de teste com contas reais. Detalhes por serviço no README.
  • Catálogos diferem por país: um título pode não existir para quem está em outra região.
  • No Prime Video, a URL costuma ficar na página da série ao trocar de episódio, então pode faltar o aviso de troca.
  • Anúncios (YouTube, Max com anúncios) desalinham o tempo até o próximo comando do host.
  • Se o navegador bloquear o play automático, clique uma vez na página ao entrar.
